## Run a Solution

1. Clone the repository: `git clone https://github.com/ojodavidoluwadarasimi/data-structures-and-algorithms.git`
2. Go into the folder: `cd data-structures-and-algorithms`
3. Run any file, for example: `python python/sorting/bubble_sort.py`

Each file runs its own tests and prints a message when they pass.

## Goal

Understand how and why each solution works, not just get it to pass.
